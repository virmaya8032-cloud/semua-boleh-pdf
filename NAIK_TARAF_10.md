# Sepuluh naik taraf Semua Boleh PDF

Kemas kini ini menambah 9 alat baharu dan menaik taraf PDF kepada Word. Katalog kini mempunyai **56 alat**. Semua editor, akaun pengguna, pentadbir dan fungsi versi terdahulu dikekalkan.

## 1. Aliran kerja bersambung

Selepas mana-mana hasil PDF siap, pilih **Alat seterusnya** dan **Sambung tanpa pilih fail semula**. Contoh: OCR → Edit PDF → Tandatangan → Mampat Ikut Saiz. Setiap langkah menggunakan hasil sebenar langkah sebelumnya, bukan dokumen asal. Fail hasil dicache dalam sesi pelayar.

Alat **Aliran Kerja PDF** pula menjalankan 1–6 langkah automatik pada backend. Pilih OCR, putar, flatten, buang metadata, nombor halaman, tera air atau mampat. Preset OCR → Flatten → Mampat disediakan. Selepas 20 minit, langkah baharu tidak dimulakan; gunakan lebih sedikit langkah/halaman jika had ini dicapai. Tetapan boleh disimpan dalam pelayar dan digunakan semula; dokumen tidak disimpan bersama preset.

Edit dan tandatangan memerlukan pilihan pengguna pada halaman, jadi gunakan butang Sambung selepas hasil siap. Dokumen dihantar secara automatik ke backend untuk alat berikutnya; pengguna tidak perlu memilih atau memuat naik fail secara manual sekali lagi. Simpan hasil sebelum menutup tab; ini belum penyimpanan dokumen awan atau pemulihan sesi.

## 2. Urus halaman dalam satu paparan

Buka **Urus Halaman PDF**. Tambah satu atau beberapa PDF dahulu, kemudian:

- Seret kad atau gunakan anak panah untuk susunan.
- Klik Salin untuk menambah salinan halaman.
- Klik Putar untuk putaran 90 darjah setiap klik.
- Klik Padam untuk mengeluarkan halaman daripada hasil.
- Simpan sebagai satu PDF.

Pratonton dipaparkan 20 kad pada satu masa. Maksimum 30 fail input dan 1000 halaman dalam hasil. Menukar, membuang atau menyusun semula senarai fail akan menetapkan semula rancangan halaman; selesaikan pilihan fail dahulu. Halaman pendua sengaja dibenarkan.

## 3. Proses banyak fail sekali gus

Buka **Proses Banyak Fail**, pilih sehingga 30 PDF, alat dan tetapan. Pilihan: mampat, PDF kepada Word/Excel/PowerPoint/Teks/JPG/PNG, putar dan flatten.

Fail diproses satu demi satu supaya RAM tidak melonjak. Selepas 20 minit, tiada fail baharu dimulakan; laporan menyatakan baki yang perlu diproses dalam kelompok lain. Hasil dalam ZIP menggunakan nama asal dengan nombor urutan supaya tiada fail tertindih. `laporan-kelompok.txt` menyatakan setiap kejayaan/kegagalan. Jika satu gagal, hasil yang lain masih disediakan; jika semua gagal, mesej ralat dipaparkan. PDF kepada JPG/PNG menghasilkan ZIP berasingan bagi setiap PDF, di dalam ZIP kelompok.

## 4. Scan kamera telefon

Buka **Scan Kamera ke PDF** dan tekan **Ambil gambar dengan kamera**. Kawalan kamera disokong mengikut peranti/pelayar; komputer boleh membuka pemilih fail biasa. JPG/PNG juga boleh dimuat naik.

Sistem cuba mengesan tepi kertas. Jika pengesanan tidak tepat, klik empat penjuru: **atas kiri → atas kanan → bawah kanan → bawah kiri**. Perspektif diluruskan menggunakan kawasan itu. Reset penjuru untuk kembali kepada pengesanan automatik atau gambar penuh. Pilih warna asal, cerahkan atau hitam putih sebelum simpan.

Dokumen scan menjadi PDF bergambar. Sambung ke OCR untuk carian/salin teks. Foto kompleks atau tepi tidak jelas mungkin tidak dikesan; dalam keadaan itu gambar penuh digunakan. Maksimum 25 megapiksel setiap gambar; gambar dikecilkan sebelum pemprosesan. Mengubah susunan/buang gambar mereset penjuru supaya koordinat tidak digunakan pada gambar salah.

## 5. PDF kepada Word lebih kemas

Pilihan **Kekalkan susun atur, jadual dan gambar** menggunakan pdf2docx untuk menghasilkan DOCX dengan kandungan boleh diedit. Pilihan **Teks sahaja** masih tersedia untuk dokumen ringkas.

Ujian dokumen contoh memastikan hasil mempunyai jadual Word dan gambar terbenam. Ini tidak menjamin reka letak sama tepat untuk semua PDF, terutama lajur kompleks, font khas dan objek bertindih. PDF imbasan perlu OCR dahulu; rupa selepas penukaran perlu disemak.

## 6. Cari dan ganti semua

Buka **Cari dan Ganti Teks**, masukkan carian dan gantian. Boleh padankan huruf besar/kecil atau perkataan penuh. Tekan **Semak padanan sebelum ganti** untuk jumlah dan halaman setiap padanan. Gantian kosong memadam teks.

Pemprosesan membuang aksara asal dan menulis teks gantian; perkataan jiran dikekalkan. Teks lebih panjang dikecilkan untuk muat ruang asal. Jika terlalu panjang, gunakan editor untuk melaras kawasan. Maksimum 1000 padanan; carian satu baris maksimum 300 aksara. Teks bersudut bebas dan merentas baris tidak disokong.

Gantian pada lapisan OCR tersembunyi di atas gambar ditolak: perubahan lapisan teks sahaja tidak mengubah perkataan dalam imej. Gunakan **Edit PDF** untuk perubahan visual pada imbasan. Gunakan **Sensor PDF** bagi pemadaman maklumat sulit.

## 7. Buang latar tandatangan

Buka **Buang Latar Tandatangan**, pilih JPG/PNG dakwat gelap pada kertas putih/cerah. Laraskan ambang latar dan semak PNG pada latar berkotak. Download PNG atau tekan **Gunakan tandatangan ini — pilih PDF**. Selepas pilih PDF, gambar telus itu sudah tersedia dalam editor untuk ditempatkan.

Ini penyingkiran latar cerah berdasarkan warna, bukan pemisahan AI bagi foto kompleks. Dakwat terlalu pucat atau latar gelap mungkin tidak sesuai. Tandatangan ini visual, tanpa sijil digital. Output maksimum 2000 × 2000 piksel; gambar editor mempunyai had 3 MB.

## 8. Mampat ikut sasaran saiz

Buka **Mampat Ikut Saiz**, pilih sasaran 0.1–50 MB dan had kualiti. Ghostscript dicuba secara bertahap: printer, ebook, kemudian screen jika had kualiti membenarkannya. Berhenti apabila sasaran dicapai; hasil terkecil digunakan. Jika input sudah kecil, salinannya dikekalkan.

Mesej hasil menyatakan sama ada sasaran berjaya. Jika belum, cuba had kualiti lebih rendah atau pisah PDF. Sasaran tidak dijamin: PDF teks atau gambar yang sudah padat mempunyai had mampatan. Unit sasaran menggunakan 1 MB = 1,048,576 bait. Semak pratonton sebelum menggunakan hasil rasmi.

## 9. Automasi dokumen

Buka **Automasi Dokumen** dan pilih tugas:

- **Nama fail:** teks selepas label pada halaman pertama menjadi nama fail.
- **Pisah ikut rujukan:** kumpulan baharu bermula apabila teks selepas label berubah. Halaman tanpa label disambung ke kumpulan sebelumnya; halaman pertama mesti ada rujukan.
- **Lampiran:** satu muka pemisah bernombor ditambah sebelum setiap dokumen; setiap lampiran disediakan berasingan dalam ZIP.

Contoh label: `No. Rujukan:`. Jika label kosong, baris pertama yang tidak kosong digunakan. Nama output dibersihkan dan diberi nombor untuk mengelakkan pertindihan. ZIP mengandungi `senarai-hasil.csv` dengan pemetaan fail dan halaman. PDF perlu mempunyai teks; scan perlu OCR dahulu. Label yang hilang atau salah pada tugas nama/pisah memberikan ralat, bukannya menamakan fail secara senyap dengan rujukan rekaan.

## 10. AI untuk PDF

Tiga mod: **Ringkaskan dokumen**, **Tanya soalan**, **Terjemah teks halaman**. Pilih bahasa Melayu/English/Tamil dan julat halaman jika perlu. Hasil ialah teks boleh disalin/download; terjemahan ini tidak membina semula susun atur PDF.

Teks halaman pilihan dihantar kepada OpenAI hanya apabila pengguna menandakan persetujuan. Kunci API kekal di backend; jangan letak dalam `VITE_*`. Secara lalai AI memerlukan log masuk. Model diarahkan menggunakan dokumen sahaja dan mengabaikan arahan dalam dokumen. Setiap petikan disemak sama ada benar-benar wujud pada halaman yang dirujuk; petikan yang tidak sepadan dibuang dan diberi nota. Petikan yang sepadan bukan jaminan tafsiran betul: semak jawapan dengan sumber.

Tetapkan pada backend:

```text
OPENAI_API_KEY=<kunci akaun OpenAI anda>
OPENAI_MODEL=<model tersedia yang menyokong Responses dan Structured Outputs>
AI_ALLOW_PUBLIC=false
```

Kedua-dua kunci/model kosong secara lalai; alat memaparkan arahan pengaktifan. Kos API berasingan daripada langganan ChatGPT. Tiada kunci sebenar dibekalkan atau panggilan AI berbayar dibuat dalam ujian ini. API disambungkan kepada `https://api.openai.com/v1/responses`, dengan `store:false`. Tetapan ini bukan janji tiada penyimpanan oleh penyedia; rujuk dasar akaun API anda.

Had: maksimum 300 halaman sumber, 120,000 aksara konteks setiap permintaan, 2,000 aksara soalan dan 8,000 token output. Dokumen melebihi had ditolak dengan arahan memilih julat, bukan dipotong senyap. Jawapan tidak lengkap tidak ditawarkan sebagai hasil berjaya. OCR diperlukan jika tiada teks.

## Kemas kini melalui GitHub Desktop

1. Buat salinan sandaran folder projek lama.
2. Extract ZIP. Salin **kandungan dalam** `semua-boleh-pdf-main` ke folder repo anda dan Replace fail kod.
3. Kekalkan `.env` sebenar dan tetapan hos sedia ada. Jangan salin `node_modules`, `dist` atau persekitaran Python tempatan.
4. GitHub Desktop: Summary `Tambah 10 naik taraf PDF` → Commit to main → Push origin.
5. Deploy semula **backend Docker** dan **frontend**. Backend memerlukan pdf2docx, OpenCV headless, NumPy dan Pillow dalam `requirements.txt`.
6. Jika mahu AI, masukkan kunci/model melalui Environment hos backend. Jangan reset pangkalan data.
7. Semak alat baharu pada komputer dan telefon selepas deploy.

## Pengesahan

**110 ujian backend dan 24 ujian frontend lulus.** Frontend berjaya dibina untuk produksi. Kebergantungan Python yang dipin dalam requirements diuji menggunakan persekitaran berasingan.

Ujian merangkumi dokumen sebenar, jadual/gambar DOCX, alpha PNG, scan perspektif, penggantian/pemadaman teks, gabungan halaman, aliran beberapa langkah, kelompok separa gagal, automasi nama/pisah/lampiran dan batas input.

AI diuji dengan respons API simulasi: bentuk permintaan, semakan petikan, julat halaman, konfigurasi dan persetujuan. Kualiti model sebenar serta sambungan berkredit belum diuji. Kamera fizikal, paparan Chromium, deployment hos dan akaun/pangkalan data sebenar belum diuji dalam sesi ini. Ujian DOM memeriksa kawalan dan perpindahan hasil antara alat, bukan menggantikan semakan pelayar.
